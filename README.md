# ML Model Failure Prediction and Early Warning System

## Objective
Build a machine learning system that detects model degradation
and generates early warnings when model performance becomes unreliable.

## Planned Stack
- Python
- pandas
- scikit-learn
- Evidently
- FastAPI
- PostgreSQL
- Docker
- Prometheus and Grafana

## Project Structure
- src/: application and ML pipeline code
- tests/: automated tests
- configs/: configuration
- data/: datasets
- notebooks/: exploratory analysis
